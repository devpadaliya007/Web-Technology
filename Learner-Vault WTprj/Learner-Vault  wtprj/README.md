# Learner-Vault: Clean Modern Edition 🎓

> **College Web Technology Project**  
> **Built Exclusively With:** Pure HTML5 & CSS3 (Zero JavaScript, Zero Frameworks)  
> **Design Philosophy:** Clean, distraction-free academic layout with concise labels and modern UI components.

---

## 📌 Project Overview

**Learner-Vault Clean** is a student-focused learning management web interface designed for university and college courses. It organizes courses, modular syllabus outlines, lecture notes, cheatsheets, and self-assessment quizzes in a clean, responsive, and intuitive interface.

All unnecessary filler text, verbose mock tokens, and complicated JavaScript scripts from the original design have been removed in favor of clean, maintainable, and high-performance HTML5 and CSS3 code.

---

## 📂 Project Pages

| Page | File | Description |
| :--- | :--- | :--- |
| **Home / Landing** | `index.html` | Platform overview, highlights, featured subjects, workflow guide, and footer. |
| **Course Catalog** | `courses.html` | Filterable subject grid with progress indicators, instructor tags, and syllabus links. |
| **Course Details** | `course-details.html` | Complete 4-unit curriculum module accordion with topics, learning outcomes, and course metadata. |
| **Student Dashboard**| `dashboard.html` | Student stats, active progress cards, pure-CSS weekly study hours bar graph, and recent activity timeline. |
| **Resource Vault** | `resources.html` | Downloadable lecture notes, PDF guides, SQL & CSS cheat sheets, and university examination papers. |
| **Practice Quiz** | `quiz.html` | Pure CSS self-assessment quiz with custom radio option selection states and results score card. |
| **Student Profile** | `profile.html` | Student academic profile, enrollment number, current semester courses, and settings form. |
| **Sign In** | `login.html` | Clean student authentication portal with demo login options. |
| **Registration** | `register.html` | Student registration form with branch and semester selectors. |
| **Admin Portal** | `admin-dashboard.html`| Faculty/admin control panel with course management table and student user roster. |
