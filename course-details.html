Course WT-301 B.Tech Computer Science • Semester 6

Web Technology & Full-Stack Fundamentals

A structured curriculum covering standard HTML5 semantics, modern CSS3 styling, Flexbox, responsive grid systems, client-server concepts, and accessibility.

Course Learning Outcomes

✓
Master HTML5 semantic elements and document hierarchy.
✓
Build responsive, mobile-first designs with CSS3 Grid & Flexbox.
✓
Implement accessible user interfaces adhering to WCAG standards.
✓
Design clean forms with native client-side validation rules.
